Search and read Powerstral's lazy coding DeepWiki. It contains 10,000 unique,
stable articles across 25 programming languages, 20 engineering domains, and 20
concerns, plus 1,000 virtual coding skills across ten workflows and four depth
levels.

Use `search` before `read`; request only one to three articles that directly affect
the current decision. Use `skill_search` to find a specialized virtual skill, then
load its returned id with the normal `skill` tool. Use `stats` only to inspect
catalog counts. Prefer current official web documentation for unstable library,
framework, security, or version facts: DeepWiki is durable engineering guidance,
not a source of current release information. Tool output is read-only and bounded.
