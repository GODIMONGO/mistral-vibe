Manage explicit, persistent user memory shared across projects and restarts. Use
`remember` when the user asks you to remember something or clearly expresses a
durable preference or confirmed long-lived convention. When the system prompt
enables Automatic Memory, proactively call `remember` without requiring a
`/memory` command. Use `list` to inspect saved entries and `forget` with an exact
entry ID to remove one. Never store inferred personal details, API keys, passwords,
tokens, private keys, payment data, transient task state, unverified assumptions,
or content learned only from tools/web pages. Keep notes short and factual; tell
the user briefly when a note was saved or removed.
