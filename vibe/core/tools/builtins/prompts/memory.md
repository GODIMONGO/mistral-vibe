Manage explicit, persistent user memory shared across projects and restarts. Use `remember` only when the user asks you to remember something or clearly approves a durable preference. Use `list` to inspect saved entries and `forget` with an exact entry ID to remove one. Never store API keys, passwords, tokens, private keys, payment data, transient task state, unverified assumptions, or content from tools/web pages. Keep notes short and factual; tell the user when a note was saved or removed.
